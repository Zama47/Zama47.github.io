## 🚀 Проекты

### 🌬️ Asthma Helper — основной проект
[![Repo](https://img.shields.io/badge/GitHub-Zama47/asthma_helper-181717?style=flat-square&logo=github)](https://github.com/Zama47/asthma_helper)
[![APK](https://img.shields.io/badge/Скачать_APK-Pre--release-brightgreen?style=flat-square)](https://github.com/Zama47/asthma_helper/releases)

**Android-приложение для людей с астмой.**
- Трекинг пикфлоуметрии с графиками (Vico Charts) и зонами нормы
- Расписание лекарств с умными напоминаниями (WorkManager) и готовой базой из 16 препаратов
- Мониторинг погоды, качества воздуха (AQI) и пыльцы через Open-Meteo API
- Автоопределение геолокации (FusedLocationProvider) + обратное геокодирование

**Стек:** Kotlin, Compose, MVVM + Clean Architecture, Hilt, Room, Retrofit, WorkManager, Vico Charts
